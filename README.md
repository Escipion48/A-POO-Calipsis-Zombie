# A-POO-Calipsis-Zombie
Este es el repositorio del proyecto de A-POO-Calipsis Zombie
Actualmente estamos montando y configurandolo todo, pronto nos pondremos con el proyecto y crearemos la primera version utilizable, muchas gracias por su paciencia.

Esta rama es la rama de development, donde se incluiran las nuevas funcionalidades, clases etc hasta que les demos la luz verde y sean incorporadas a la rama maestra, (main), si alguno de nosotros tiene problemas, ve que hay que añadir algo, falta algo y un largo ect y es necesario informarlo (cualquier cosa que no se arregle con un par de lineas de codigo) mediante issues. De este modo podemos tener un historial de los cambios, y quien y cuando se han realizado. Además podriamos llegar a crear mas ramaas de desarrollo en caso que sea necesario, pero de momento con esta será suficiente.
